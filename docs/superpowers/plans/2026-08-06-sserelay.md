# Generic High-Performance SSE Relay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace SDK per-event stream decoding with a raw-byte SSE relay in `pkg/sserelay` for the three streaming endpoints, keeping all existing proxy semantics and usage capture.

**Architecture:** `pkg/sserelay` reads SSE frames incrementally from `io.Reader`, forwards raw bytes unchanged with adaptive flush (first event immediate, then 4KiB threshold / 1ms timer), and calls an observer only for usage extraction. `pkg/aiclient` adds raw streaming methods built on the shared `http.Client` (SDK request layer is internal, so raw HTTP requests with injected auth headers are used). `internal/proxy` migrates the three streaming paths and keeps the SDK for non-streaming.

**Tech Stack:** Go 1.26.5, standard library, gjson v1.18.0 (promoted to direct dependency), bufio, sync.Mutex, time.Timer, testify.

## Global Constraints

- `pkg/sserelay` does not set a frame size limit; frames accumulate incrementally and are dropped at stream end.
- Raw bytes are forwarded unchanged: no field reordering, no newline rewriting, no re-marshaling.
- Flow end = reader EOF / upstream read error / ctx cancel; `[DONE]` is observer info only, never generated or removed by relay, never used as flow-end detection.
- Flush rules: first event flushes immediately; after that flush when `pending >= FlushBytes`; a timer flushes after `FlushInterval` when `pending > 0`; relay stops the timer and waits for the timer goroutine before releasing the writer.
- Observer runs after the raw frame is written, must not block relay, must not modify written bytes; observer panics are not swallowed.
- No Flusher on the writer: relay still writes complete output, no panic, no busy-loop.
- usage extraction paths: openai-chat `usage.prompt_tokens|completion_tokens|total_tokens`; openai-responses event `response.completed` → `response.usage.input_tokens|output_tokens|total_tokens`; anthropic `message_start` → `message.usage.input_tokens`, `message_delta` → `usage.output_tokens`.
- Defaults: `FlushBytes = 4096`, `FlushInterval = 1ms`. First-event-immediate-flush stays the default (variant B measured later in an A/B test).
- `gjson` v1.18.0 moves from indirect to direct dependency in `go.mod`.
- Proxy semantics unchanged: no failover after first byte, upstream read error → ErrAbort, client write failure releases slot and marks error, success resets account, UsageCapture=false never Records, 4xx passes through upstream status+body.
- Non-streaming endpoints keep the official SDKs.
- Verify with `go test ./...`, `go vet ./...`, `golangci-lint run ./...`, and `go test -race ./pkg/sserelay ./internal/proxy`.

```go
// Package sserelay 提供原始字节级 SSE relay：从 io.Reader 增量读取 SSE 帧，
// 原样转发给 http.ResponseWriter，自适应批量 Flush，并以 Observer 旁路暴露
// 事件信息（仅用于 usage 提取，不参与转发决策）。
package sserelay

import (
	"bufio"
	"bytes"
	"context"
	"io"
	"net/http"
	"sync"
	"time"
)

// Event 是一次 SSE 事件的旁路视图。
type Event struct {
	Raw   []byte // 完整原始帧（含结尾空行）
	Event []byte // event: 字段值；data-only 帧为空
	Data  []byte // 合并后的 data: payload（多行以 \n 连接）
}

// Observer 在帧原样写出后调用；不得阻塞 relay，不得修改已写出的字节。
type Observer func(Event)

type Config struct {
	FlushBytes    int           // 缓冲达到该值立即 flush；0 时默认 4096
	FlushInterval time.Duration // 距上次 flush 达到该值时 timer flush；0 时默认 1ms
	Observer      Observer
}

type relay struct {
	ctx context.Context
	dst http.ResponseWriter
	bw  *bufio.Writer
	fl  http.Flusher
	cfg Config

	mu       sync.Mutex // 保护 bw/pending/flushTimer
	pending  int
	lastTick time.Time

	timer     *time.Timer
	timerDone chan struct{}
}

// Relay 把 src 的 SSE 流原样转发到 dst。流结束 = EOF / 读错误 / ctx 取消。
func Relay(ctx context.Context, dst http.ResponseWriter, src io.Reader, cfg Config) error {
	if cfg.FlushBytes <= 0 {
		cfg.FlushBytes = 4096
	}
	if cfg.FlushInterval <= 0 {
		cfg.FlushInterval = time.Millisecond
	}
	r := &relay{
		ctx: ctx, dst: dst, cfg: cfg,
		bw:        bufio.NewWriterSize(dst, 8192),
		timerDone: make(chan struct{}),
	}
	r.fl, _ = dst.(http.Flusher)
	r.startFlushTimer()

	err := r.run(src)
	r.stopFlushTimer()
	// 读循环退出后（timer 已停、goroutine 已退出）再 flush 残余并归还 writer
	r.mu.Lock()
	r.flushLocked()
	r.mu.Unlock()
	return err
}

func (r *relay) run(src io.Reader) error {
	br := bufio.NewReaderSize(src, 8192)
	var (
		frame bytes.Buffer // 当前帧原始字节
		data  []byte       // 当前帧 data payload（合并）
		event []byte       // 当前帧 event 字段
	)
	flushFrame := func() error {
		if err := r.write(frame.Bytes()); err != nil {
			return err
		}
		if r.cfg.Observer != nil {
			r.cfg.Observer(Event{Raw: frame.Bytes(), Event: event, Data: data})
		}
		frame.Reset()
		data = data[:0]
		event = event[:0]
		return nil
	}
	for {
		// 空行 = 帧结束
		line, err := br.ReadSlice('\n')
		if len(line) > 0 {
			if len(line) == 2 && line[0] == '\r' && line[1] == '\n' {
				// 空行（CRLF）
				frame.Write(line)
				if err := flushFrame(); err != nil {
					return err
				}
				if err != nil {
					return r.normalize(err)
				}
				continue
			}
			if len(line) == 1 && line[0] == '\n' {
				// 空行（LF）
				frame.Write(line)
				if err := flushFrame(); err != nil {
					return err
				}
				if err != nil {
					return r.normalize(err)
				}
				continue
			}
			frame.Write(line)
			field, value := splitField(line)
			switch string(field) {
			case "event":
				event = append(event[:0], value...)
			case "data":
				if len(data) > 0 {
					data = append(data, '\n')
				}
				data = append(data, value...)
			}
		}
		if err == io.EOF {
			return nil
		}
		if err == bufio.ErrBufferFull {
			continue // 长行：继续累积该行剩余部分
		}
		if err != nil {
			return r.normalize(err)
		}
		if err := r.checkCancel(); err != nil {
			return err
		}
	}
}

// splitField 解析 "name: value" 行；无冒号或注释行返回 ("", nil)。
func splitField(line []byte) ([]byte, []byte) {
	i := bytes.IndexByte(line, ':')
	if i < 0 {
		return nil, nil
	}
	name := line[:i]
	if len(name) == 0 || name[0] == ':' { // 注释行
		return nil, nil
	}
	val := line[i+1:]
	if len(val) > 0 && val[0] == ' ' {
		val = val[1:]
	}
	// 去掉行尾 \n / \r\n
	for len(val) > 0 && (val[len(val)-1] == '\n' || val[len(val)-1] == '\r') {
		val = val[:len(val)-1]
	}
	return name, val
}

func (r *relay) normalize(err error) error {
	if err == context.Canceled || r.ctx.Err() != nil {
		return context.Canceled
	}
	return err
}

func (r *relay) checkCancel() error {
	select {
	case <-r.ctx.Done():
		return context.Canceled
	default:
		return nil
	}
}

func (r *relay) write(p []byte) error {
	r.mu.Lock()
	defer r.mu.Unlock()
	if _, err := r.bw.Write(p); err != nil {
		return err
	}
	r.pending += len(p)
	first := r.lastTick.IsZero()
	r.lastTick = time.Now()
	if first {
		// 首事件立即 flush，保证首字节延迟
		return r.flushLocked()
	}
	if r.pending >= r.cfg.FlushBytes {
		return r.flushLocked()
	}
	return nil
}

func (r *relay) startFlushTimer() {
	r.timer = time.NewTimer(r.cfg.FlushInterval)
	go func() {
		defer close(r.timerDone)
		for {
			select {
			case <-r.ctx.Done():
				return
			case <-r.timer.C:
				r.mu.Lock()
				r.flushLocked()
				r.mu.Unlock()
				r.timer.Reset(r.cfg.FlushInterval)
			}
		}
	}()
}

func (r *relay) stopFlushTimer() {
	r.timer.Stop()
	<-r.timerDone // 等 timer goroutine 退出后才允许释放 writer
}

func (r *relay) flushLocked() {
	if r.pending == 0 {
		return
	}
	if err := r.bw.Flush(); err != nil {
		// Flush 失败（客户端断开）：记录到返回路径
		r.pending = 0
		return
	}
	r.pending = 0
	if r.fl != nil {
		r.fl.Flush()
	}
}
```

Notes the implementer must follow exactly:

- `bufio.Writer` is constructed on `dst` directly (not pooled) in this task; pooling is a later optimization and must not be added here.
- The timer goroutine exits on `ctx.Done`; `stopFlushTimer` waits on `timerDone` before any final flush, so the writer is never touched after relay returns.
- `flushLocked` never returns an error from `Flush` because a client-disconnect flush failure cannot be recovered; the write path reports errors from `bw.Write`.
- The `flusherRecorder` test wrapper implements `http.Flusher` so flush counts are observable.
- `bytes.Buffer` and `bufio.Reader` imports are used; `io.EOF` handling ends the stream without treating a trailing frame without blank line as an error.

```go
// --- 流式原始请求（SSE relay 用） ---
// SDK 的请求层在 internal/requestconfig（不可 import），故基于共享 http.Client

func (f *Factory) ChatCompletionStreamRaw(ctx context.Context, tpl *domain.Template, key string, body []byte) (*http.Response, error) {
	return f.rawPost(ctx, tpl, "chat/completions", "Bearer "+key, body)

	return f.rawPost(ctx, tpl, "responses", "Bearer "+key, body)

}

// rawPost 构造并发出原始 POST；authHeader 为 Authorization 值（anthropic 用
// x-api-key，传 key 本身）。
func (f *Factory) rawPost(ctx context.Context, tpl *domain.Template, path, auth string, body []byte) (*http.Response, error) {
	u, err := url.Parse(tpl.BaseURL)
	if err != nil {
		return nil, err
	}
	rel, err := url.Parse(path)
	if err != nil {
		return nil, err
	}
	full := u.ResolveReference(rel)
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, full.String(), bytes.NewReader(body))
	if err != nil {
		return nil, err
	}
	req.Header.Set("Content-Type", "application/json")
	if path == "v1/messages" {
		req.Header.Set("x-api-key", auth)
	} else {
		req.Header.Set("Authorization", auth)
	}
	return f.hc.Do(req)
}
```

Notes:

- `url.Parse("chat/completions")` as a relative reference with `ResolveReference` against `https://x/v1` yields `https://x/v1/chat/completions`; against `https://x/v1/` yields `https://x/v1/chat/completions`; against `https://x/proxy/v1` yields `https://x/proxy/v1/chat/completions` (relative reference appends to the base path). This is exactly the SDK's path semantics.
- `auth` for anthropic is the bare key; the `x-api-key` header is set in `rawPost` based on the path argument, not passed through `Authorization`.
- Non-2xx responses are returned as `*http.Response` (caller inspects status), not converted to errors — matches the 4xx passthrough requirement.

```go
// readUpstreamBody 读取并关闭非 200 响应的 body（4xx/5xx 透传用）。
func readUpstreamBody(resp *http.Response) []byte {
	b, err := io.ReadAll(io.LimitReader(resp.Body, 1<<20))
	if err != nil {
		return nil
	}
	return b
}

// setStreamFlag 把原始请求体里的 "stream" 字段设为给定值（流式注入用）。
// 用 map 重写避免对任意 JSON 结构做字符串手术；失败返回 nil。
func setStreamFlag(body []byte, v bool) ([]byte, error) {
	var m map[string]any
	if err := json.Unmarshal(body, &m); err != nil {
		return nil, err
	}
	m["stream"] = v
	return json.Marshal(m)
}
```
